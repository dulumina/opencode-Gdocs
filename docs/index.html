OpenCode V2 plugin

Google Drive & Docs
inside OpenCode

Search, read, create and edit Google Docs without leaving your session. One OAuth login, tokens refreshed and stored locally.

View on GitHub Install

Install

1

Create a Desktop OAuth client

In Google Cloud Console, create a Desktop app OAuth client, download the client JSON, and enable the Drive and Docs APIs.

2

Run the installer

Copies the plugin and client JSON into your global OpenCode config.

git clone https://github.com/dulumina/opencode-Gdocs.git cd opencode-Gdocs ./install.sh /path/to/client_secret.json
3

Install dependencies and authorize

cd ~/.config/opencode && bun install

Restart OpenCode, then ask it to run google_auth. The browser opens Google's consent page once.

Tools

google_auth

Connect through Google OAuth.

google_auth_status

Check the saved connection.

google_drive_search

Search Drive by file name or text.

google_drive_list

List recent files, optionally by folder.

google_drive_read

Read Docs and plain-text files.

google_docs_create

Create a document with initial text.

google_docs_append

Append text to an existing document.

google_docs_replace

Replace a document's full text.

Auth lifetime

Testing mode expires tokens every 7 days.

While the OAuth consent screen is in Testing, Google expires refresh tokens after a week. Publish the app (Google Auth Platform → Audience → Publish app) and authorize once more to get a long-lived token. Unverified apps show a warning and are capped at 100 users — fine for personal use.

No build step. Requires OpenCode V2. github.com/dulumina/opencode-Gdocs
